    Trois vues synchronisées

    • Canevas : vue visuelle SVG, éléments repositionnables à la souris et au clavier.
    • Plan : liste hiérarchique des cadres et éléments, avec indication des liens.
    • Tableau : table triable de tous les éléments avec leurs propriétés.

    Modèle de données

    Le tableau contient des éléments de types : post-it (texte + couleur), forme (rectangle, cercle, triangle, losange), texte libre, carte (titre + description), cadre (regroupement), lien (connecteur orienté entre deux éléments, avec étiquette optionnelle), dessin à main levée, commentaire, carte mentale, kanban, tableau de données, bloc de code et carte recto-verso. Post-its et cartes acceptent des étiquettes ; tout objet accepte des réactions.

    Persistance

    Les tableaux sont sauvegardés automatiquement dans le navigateur (localStorage). Vous pouvez aussi exporter en JSON (réimportable) ou en Markdown (lisible).

    Limites

    • Pas de collaboration en temps réel : l'état est local. Le format JSON est conçu pour être sérialisable en vue d'un ajout futur de temps réel.
